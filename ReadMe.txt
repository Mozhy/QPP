This is souces codes of Implementation a novel method for Query Performance Prediction(QPP) task.
In our Implementation we predict performance of BM25 ranking model.We use 3 sets of queries. namely:Ms-marco Development set, DL-Hard and DL-2019. Also we use 2 types of clustering algorithms. ie: K-means and K-medoids.But in the code display, we only used Ms-marco Development set and K-means.
